# TailorConnect — Product Specification & Vision

## 1. Executive Summary
TailorConnect is an AI-powered, PWA-first digital marketplace and operating system for custom clothing, tailor studios, and bespoke boutiques. 

## 2. Core Problem & Value Proposition
In traditional tailoring, customers suffer from uncertainty around:
* Who can do the specific stitch work (bridal blouse, sherwani, bespoke suit, etc.).
* What the transparent itemized cost will be.
* When the garment will be ready.
* Whether the tailor accepted the order.
* What stage the stitching is in right now.

TailorConnect bridges this gap with an Amazon-style visual milestone tracking timeline, transparent itemized quotes, contextual Q&A, and hybrid deterministic matching.

## 3. User Personas
1. **Customer:** Needs customized fit, specific design styling, transparent quoting, reliable delivery deadlines, and step-by-step progress visibility.
2. **Tailor / Boutique:** Needs steady local demand, structured customer requirement briefs with reference photos, simple itemized quoting, scheduled fitting appointments, and easy order status tracking.
3. **Admin:** Marketplace steward ensuring business verification, platform health, order resolution, and catalog quality.

## 4. MVP Scope Boundaries
- **In Scope (V1):** Natural language requirement parsing, hybrid geo-matching, tailor capability profiles, portfolio showcase, stitching requests & photos, itemized quotes, quote acceptance, online mock & offline cash/UPI payment recording, state machine order lifecycle, vertical timeline tracking, calendar appointments, verified customer reviews, admin verification console, and PWA installation.
- **Out of Scope (Deferred to V2/V3):** Fabric marketplace, body 3D scanning, virtual try-on, multi-branch ERP, karigar piece-rate management, payroll, warehouse inventory.
